1.  **HTML (Hypertext Markup Language)**: HTML เป็นภาษาเครื่องมือที่ใช้ในการสร้างโครงสร้างและเนื้อหาของเว็บไซต์ เช่น การสร้างตาราง, ตัวอักษร, รูปภาพ, ลิงก์ เป็นต้น HTML เป็นภาษาเครื่องมือที่ใช้ในการสร้างโครงสร้างและเนื้อหาของเว็บไซต์ เช่น การสร้างตาราง, ตัวอักษร, รูปภาพ, ลิงก์ เป็นต้น
2.  **CSS (Cascading Style Sheets)**: CSS เป็นภาษาเครื่องมือที่ใช้ในการกำหนดรูปแบบและลักษณะของเว็บไซต์ เช่น การกำหนดสี รูปแบบตัวอักษร, การจัดเรียงส่วนประกอบ เป็นต้น CSS เป็นภาษาเครื่องมือที่ใช้ในการกำหนดรูปแบบและลักษณะของเว็บไซต์ เช่น การกำหนดสี รูปแบบตัวอักษร, การจัดเรียงส่วนประกอบ เป็นต้น
3.  **JavaScript**: JavaScript เป็นภาษาเครื่องมือที่ใช้ในการสร้างการโต้ตอบและฟังก์ชันบนเว็บไซต์ เช่น การสร้างการโต้ตอบ, การแสดงผลข้อมูล, การควบคุมการแสดงผล เป็นต้น JavaScript เป็นภาษาเครื่องมือที่ใช้ในการสร้างการโต้ตอบและฟังก์ชันบนเว็บไซต์ เช่น การสร้างการโต้ตอบ, การแสดงผลข้อมูล, การควบคุมการแสดงผล เป็นต้น
