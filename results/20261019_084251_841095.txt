Docker image และ Docker container เป็นสองส่วนสำคัญของ Docker ที่ช่วยให้สามารถจัดการและจัดเก็บแอปพลิเคชันบนเครื่องมือคลาวด์หรือเครื่องมือที่ไม่มีการจัดการได้

**Docker Image**

Docker image คือไฟล์ข้อมูลที่เก็บข้อมูลเกี่ยวกับระบบปฏิบัติการและแอปพลิเคชันที่จะถูกติดตั้งบนเครื่องมือ Docker Docker image เป็นไฟล์ .dockerfile ที่มีรายละเอียดเกี่ยวกับขั้นตอนการสร้างระบบปฏิบัติการและแอปพลิเคชัน รวมถึงข้อมูลเกี่ยวกับขั้นตอนการสร้างและติดตั้งระบบปฏิบัติการและแอปพลิเคชัน

**Docker Container**

Docker container คือสภาพแวดล้อมที่แอปพลิเคชันถูกสร้างและติดตั้งบนเครื่องมือ Docker Docker container เป็นไฟล์ .docker container ที่เก็บข้อมูลเกี่ยวกับแอปพลิเคชันที่ถูกสร้างและติดตั้งบนเครื่องมือ Docker

**ความแตกต่างระหว่าง Docker image และ Docker container**

*   Docker image คือไฟล์ข้อมูลที่เก็บข้อมูลเกี่ยวกับระบบปฏิบัติการและแอปพลิเคชันที่จะถูกติดตั้งบนเครื่องมือ Docker ในขณะที่ Docker container คือสภาพแวดล้อมที่แอปพลิเคชันถูกสร้างและติดตั้งบนเครื่องมือ Docker
*   Docker image สามารถสร้างได้เพียงครั้งเดียว ในขณะที่ Docker container สามารถสร้างได้หลายครั้ง
*   Docker image เก็บข้อมูลเกี่ยวกับขั้นตอนการสร้างและติดตั้งระบบปฏิบัติการและแอปพลิเคชัน ในขณะที่ Docker container เก็บข้อมูลเกี่ยวกับแอปพลิเคชันที่ถูกสร้างและติดตั้งบนเครื่องมือ Docker
